# Requirements

## Setup

### Local clone and one-click run

作为在 Windows 上的开发者，我希望直接从 https://github.com/ttsdx/inktide 把仓库克隆到 `D:\coinStudio\surfing`，并编写一键运行脚本，这样不用敲命令就能安装依赖并启动游戏。

### Keep local in sync with remote

作为开发者，我希望把远程更新拉取到本地，让这台机器与 GitHub 远程保持一致。

## Documentation

### Understand the project and keep docs current

作为开发者，我希望先了解项目，再更新项目文档，让文档描述当前代码库，而不是过时的目录树。

## Controls

### Invert left/right steering

作为玩家，我希望左右控制反向，这样按左会转向现在按右的那一侧，键盘、手柄和触屏一致。

## Race

### Reverse racing-line chevrons

作为玩家，我希望引导绿线上的箭头反向，让箭头指向与现在相反的方向。
